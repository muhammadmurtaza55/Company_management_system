How to Configure PostgreSQL in .env

1. In the project root folder, copy the example environment template:

copy .env.example .env

2. Open .env and set your PostgreSQL connection details. Choose either option below:

# OPTION A: Full Connection URI (Local or Cloud like Render/Neon/Supabase)
DATABASE_URL=postgresql+psycopg://postgres:your_secret_password@localhost:5432/company_management_db

# OPTION B: Discrete Credentials
DB_USER=postgres
DB_PASSWORD=your_secret_password
DB_HOST=localhost
DB_PORT=5432
DB_NAME=company_management_db

3. Ensure your PostgreSQL server is running and the database exists:

# Using PostgreSQL CLI:
createdb company_management_db

# Or in psql shell:
CREATE DATABASE company_management_db;

4. Restart the Flask application and click Run Live Connection Test above.

Troubleshooting Checklist
  • Is PostgreSQL running? Check Windows Services or Docker to verify the PostgreSQL service is active.
  • Are the credentials correct? Check DB_USER and DB_PASSWORD in your .env file.
  • Does the database exist? Make sure the database named in DB_NAME or DATABASE_URL has been created.
  • Is the port accessible? The default PostgreSQL port is 5432. Check if another port was assigned.
